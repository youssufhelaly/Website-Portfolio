I built a small version of this internship.

An AI agent reads the compiler's notes on why it couldn't optimize some C code, then tries a fix. A test lab I built keeps the fix only if the output is still correct and the speedup is real.

  1. The compiler explains. clang's optimization remarks, e.g. "loop not vectorized: cannot vectorize uncountable loop."
  2. The agent tries a fix. It edits the source or the compiler flags, using the lab's tools.
  3. The lab decides. Correct output at three input sizes, repeated A/B timing, and a 95% confidence interval. The agent can't overrule it.

Why it fits this role

  • The posting's core loop: agents running compilers and benchmarks, reading the feedback, recommending next steps.
  • Measuring correctness, runtime, and compile time, instead of trusting the agent's word.
  • Reliable agent-to-tool interfaces, which is what I build now at Autodesk: an LLM agent with secure MCP tools.
